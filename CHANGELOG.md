# Changelog

## 1.0.0

* Initial release with the following features:
  * Play single tracks or playlists
  * Full playback controls (play, pause, stop, seek, next, previous)
  * Repeat and shuffle modes
  * Volume control
  * Background playback with notification controls
  * Standard and customizable UI components:
    * Full-size audio player widget
    * Mini player widget
    * Custom audio player widget with configurable icons, colors, and styles
    * Custom mini player widget with configurable icons, colors, and styles
  * BLoC state management
  * Comprehensive documentation and examples
